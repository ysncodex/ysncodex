### Nexus-ERP — Beans & Butter

Production POS and operations platform built for **Beans & Butter Cafe**, covering orders, payments, inventory, expenses, fund management, transactions, and financial reporting.

**Engineering highlights**
- React + TypeScript frontend
- Express.js + Prisma + PostgreSQL backend
- JWT authentication and RBAC
- Cash, bank, and bKash transaction workflows
- Dhaka-timezone business-day reporting
- Touch-first POS interactions based on real staff usage

**Live Demo:**
